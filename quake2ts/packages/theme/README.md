# @quake2ts/theme

A Quake look for a strata-react app, in CSS only. Import it after strata-react's default look:

```css
@import "tailwindcss";
@import "strata-react/strata.css";
@import "@quake2ts/theme/quake.css";
```

What it changes, and through which strata-react hook:

| Part | Look | Hook |
|---|---|---|
| Colours | Olive gunmetal ground, HUD amber primary (rust in light), phosphor-green focus and active row | Token contract (`:root`, `.dark`), generated by `scripts/palette.mjs` |
| Faces | Teko for titles, headings, pane names and figures; VT323 for code and paths; body stays Instrument Sans | `@theme` `--font-display`, `--font-mono`; `--figure-font`; type-step variables |
| Radii, overlay shadow | Machined (2/3/4 px), a hard rim and a deep drop | `@theme` `--radius-*`, `--shadow-overlay` |
| Grounds | Fine grain and broad stains from SVG fractal noise | `.bg-background`, `.bg-card`, `[data-pane]` (class names: no hook) |
| Pane headers | Metal plate, name in HUD ink, capitals | `[data-pane] > header > h2` (Workspace's markup: no hook) |
| Buttons | Pressed plates, lit top edge | `data-variant` |
| Screen top bar | `hud-bar` utility: plate plus hazard stripes | Opt-in class |
| Panels | `hud-panel` utility: bevelled plate with corner bolts | Opt-in class |

Nothing is taken from id Software's art; every texture is drawn by the browser.

The palette is code. Change seeds or ladders in `scripts/palette.mjs`, run `pnpm --filter @quake2ts/theme palette`,
and `pnpm --filter @quake2ts/theme test` checks the file is current and every text, edge and status pair clears
WCAG contrast in both schemes.
